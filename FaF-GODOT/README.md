# FaF (FlingAndFight) (Godot) (C#)
Fling And Fight is a physics sandbox game centered around the grabline.
It includes many systems, alongside optional worldbuilding in the form of worlds.

The grabline is a gear designed to allow the user to pick up and remotely throw/fling objects around. It isnt very precise but works exelently and has many resulting mechanics (such as flying for example). The game revolves around this gear, even going as far as having it be the default gear when no others are held.
